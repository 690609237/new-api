# 模型广场定价展示设计

## 适用范围

本文档记录模型广场列表卡片与模型详情页的定价展示约定。它描述本项目的价格口径、信息层级和布局规则，后续修改模型定价 UI 时应以此为准。

## 价格口径

模型价格同时存在两种展示口径：

- **官方定价**：模型官方价格，保留原始货币单位，用于对比参考。
- **平台分组定价**：平台按用户分组、倍率和充值配置计算后的实际价格，使用统一的 `✦` 平台积分标记。

即使官方货币与平台积分当前按 1:1 换算，也必须在展示上区分两者，不能因为数值相同而合并单位。

## 列表卡片

- 未选择分组时，显示模型启用分组中最低的有效平台价格；选择分组后，显示所选分组价格。
- 平台价格是主要信息，官方价格只作为对比基准，使用更小字号和低对比度样式。
- 官方价格不在每个输入、输出价格下重复完整的“官方定价”文案，使用紧凑的“官”标记；完整含义仍须通过辅助文本和无障碍语义保留。
- 输入、输出、缓存和按次计费价格项统一采用无底色、无装饰边框的布局，避免不同价格类型出现不一致的色块。
- `✦` 平台积分标记只用于平台价格，不用于官方价格；钱包余额、用量统计和看板总额度等平台积分摘要也复用同一标记。

## 详情页层级

定价区域直接并列展示两个区域：

1. **官方定价**
2. **平台分组定价**

两者之上不再增加泛化的“定价”标题或额外容器层，避免出现“定价 → 官方定价”和“定价 → 平台分组定价”的重复层级。

### 动态计费

动态模型的完整分档、条件和计费规则属于官方定价的明细，不是第二套价格来源：

- 只保留一个“官方定价”标题。
- “动态计费”用于表达计费模式或规则明细，不再重复包裹一层“官方定价”。
- 官方价格保持原始货币单位；平台分组动态价格使用积分图标，并按分组展示。

## 价格网格

静态 Token 模型的输入、输出、缓存、缓存写入、图片和音频等单价使用统一的响应式价格网格：

- 桌面端优先并列展示同类价格，缓存不因为属于次级价格而单独落到下一行。
- 窄屏自动换行，不以横向溢出换取并排效果。
- 同一网格内的价格卡保持相同的标签、数值和单位层级。

## 设计原则

- 先区分价格口径，再决定颜色和层级；不要用重复文案堆叠解释。
- 官方价是比较基准，平台价是实际决策信息，视觉权重应保持克制的主次关系。
- 一个概念只保留一个标题层级；计费模式、价格来源和价格明细不要混用同名标题。
- 同类数值保持对齐，优先通过网格、间距和字号建立秩序，少用大面积底色。
